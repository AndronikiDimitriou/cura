# Cura

**Your personal medication and health companion.**

Cura is a mobile application designed to help users manage medication schedules and everyday health routines.

## Installation

Visit the [Cura installation page](https://andronikidimitriou.github.io/cura/install.html) for installation instructions.

### Android
[Download Cura for Android (APK)](https://github.com/AndronikiDimitriou/cura/releases/download/v2.2-public-20261122/Cura.apk)

### iOS
[Download Cura for iOS (IPA)](https://github.com/AndronikiDimitriou/cura/releases/download/v2.2-ios-public-20261122/Cura.ipa)

**Note:** iOS installation requires a compatible signing and installation method, such as SideStore.
